# חילוץ רישיונות יבואן רכב — README

סקריפט פייתון שקורא קבצי `.docx` של רישיונות יבואן (משרד התחבורה) ומייצא אותם לקובץ אקסל מסודר.
תומך בשלושת סוגי הרישיונות: **יבואן ישיר, יבואן עקיף, יבואן זעיר**.

---

## 1. התקנה (פעם אחת)

```
pip install python-docx pandas openpyxl
```

## 2. מבנה התיקייה

```
C:\PY\Importers\
├── extract_licenses.py      ← הסקריפט
├── classifications.csv      ← טבלת תרגום סיווגים (חובה, ליד הסקריפט!)
├── README.md                ← הקובץ הזה
└── docs\                    ← תת-תיקייה עם כל קבצי ה-docx
    ├── חברה_א.docx
    └── ...
```

`extract_licenses.py` ו-`classifications.csv` **חייבים לשבת באותה תיקייה**.

## 3. הרצה

```
cd C:\PY\Importers
python extract_licenses.py C:\PY\Importers\docs licenses.xlsx
```

- פרמטר 1 = תיקיית קבצי ה-docx (לא נכנס לתת-תיקיות)
- פרמטר 2 = שם קובץ האקסל שייווצר
- **סגור את licenses.xlsx באקסל לפני הרצה חוזרת**, אחרת הכתיבה תיכשל

---

## 4. קבצי הפלט

נוצרים אוטומטית בתיקייה שממנה מריצים:

### `licenses.xlsx` — 6 גיליונות

| גיליון | תוכן |
|---|---|
| `ישיר-חברות` | שורה לחברה |
| `ישיר-תוצרים` | שורה לתוצר |
| `עקיף-חברות` | שורה לחברה |
| `עקיף-תוצרים` | שורה לתוצר, כולל סוכן ראשי/משני |
| `זעיר-חברות` | שורה לחברה (לזעיר אין תוצרים) |
| `תוצרים-DISTINCT` | רשימת תוצרים ייחודית לטעינה לטבלת REFERENCE |

גיליונות התוצרים מקושרים לגיליונות החברות לפי עמודת **ח.פ** (יחס אחד-לרבים).

### `extraction.log`
יומן ריצה. INFO לכל קובץ, WARNING לבעיה (שדה חסר, תאריך לא תקין), ERROR + traceback לקובץ שנכשל.
**לבדוק אחרי כל ריצה.**

### `unknown_classifications.csv`
נוצר רק אם היו סיווגי רכב שלא קיימים ב-`classifications.csv`.
מכיל: ערך, מספר מופעים, קובץ לדוגמה. **לבדוק אחרי כל ריצה.**
(נמחק אוטומטית בתחילת כל ריצה, כדי שלא יישאר קובץ ישן מטעה.)

## 5. מה הסקריפט מחלץ

**ברמת חברה:** ח.פ או מספר עוסק מורשה, סוג ישות (תאגיד רשום / עוסק מורשה), שם חברה (כולל יחידים — "למר X"), סוג רישיון, תאריך מתן הרישיון, תאריך תוקף הרישיון, שם המנהל המאשר, תאריך עדכון נספח א', סטטוס ביטול, סטטוס OCR.

**ברמת תוצר:** תוצר, יצרן, רשימת סיווגים (מקור + יעד לאחר תרגום), תאריך תוקף, סוכן ראשי/משני + תאריך תוקף לכל אחד (עקיף), תנאים והגבלות, סטטוס OCR.

**סטטוס OCR:** "הצליח" = כל השדות חולצו; "חלקי" = שדה חסר או סיווג לא מתורגם.

---

## 6. עדכון טבלת התרגום (`classifications.csv`)

אם `unknown_classifications.csv` לא ריק:
1. פתח את `classifications.csv` (שמור כ-UTF-8).
2. הוסף שורה לכל ערך: `מקור,יעד` — למשל `אוטובוסים,M3`
3. הרץ שוב. **אין צורך לגעת בקוד.**

---

## 7. פורמטים נתמכים (נבדקו על קבצים אמיתיים)

הסקריפט מטפל בשונות רבה בפורמט המקור:
- סיווגים בסוגריים `פולקסווגן (M1,M2,N1)`, בפסיקים `טויוטה M1, M2`, ברווחים `טויוטה M1 N1 M2`
- סוגריים לא מאוזנים במקור: `DONGFENG M1 M2))`, `איווקו ((N1`
- קודים דבוקים בטעות: `GMC M1 N1M2` → M1, N1, M2
- תאים ממוזגים (אופקית ואנכית) בטבלאות Word
- סוכן משני בשורת המשך, עם תאריך תוקף נפרד משלו
- טבלאות "יתומות" ללא כותרת (פיצול נספח)
- כותרות משתנות: "סוכן מורשה" / "דילר" / "תוקף חוזה הדילר"

## 9. סטטוס ומשימות פתוחות

**מה עובד:** כל שלושת סוגי הרישיונות, כולל DISTINCT.

**פתוח — דורש החלטה עסקית:**

1. **7 סיווגים לא ממופים.** צריך להוסיף ל-classifications.csv:
   משאיות, אוטובוסים, נגררים, נתמכים, נתמך, נגררים/נתמכים, חשמלי.
   הצעה: `משאיות → N2, N3` · `אוטובוסים → M2, M3` · `נגררים/נתמכים → O1, O2, O3, O4`
   (המסמכים לא מציינים משקל, ולכן אי אפשר לקבוע תת-קטגוריה יחידה.)

2. **איחוד כפילויות בשמות תוצרים.** ברשימת ה-DISTINCT יש כפילויות:
   - שגיאות כתיב: קאדילק/קאדילאק/קדילאק, קרייזלר/קרייזךר, ניסן/ניסאן, טויוטה/טיוטה
   - עברית מול אנגלית: בומברדייה/BRP, מאן/MAN, אופל/OPEL, איווקו/IVECO
   - קיצורים: מרצדס/מרצדס בנץ

   **הקוד אינו מאחד אותן** — זו החלטה עסקית.
   הצעד הבא: לאשר טבלת מיפוי, ואז להוסיף קובץ `product_aliases.csv` שהקוד יקרא (באותו עיקרון כמו classifications.csv).

   **אזהרה חשובה:** יש מותגים עם אותו יצרן שאסור לאחד —
   מיני ≠ ב.מ.וו · לקסוס ≠ טויוטה · ג'נסיס ≠ יונדאי · קופרה ≠ סיאט · סמארט ≠ מרצדס · SHERCO ≠ SCORPA
